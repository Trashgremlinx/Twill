Twill

A Society of Fur toolkit for Wolvden

version 0.34.0

What is Twill?

Twill reads the page you already have open, allows you to expand on details you otherwise would need a separate document to do and gives you space to grow your pack in a lore rich environment.

Hover over a gene and get expanded details on where it comes from, how it might look bred with another marking and if they can be a combo. Maybe you want to add more detail to your wolf that you simply don't have the ability to see at a glance without a separate lore document. Breeding challenges and planning your pack has become easier than ever.

Twill will never play the game for you, we leave that to you!

Under the hood

All 14, each with what it does and a slice of what it actually draws. Pick one. They repaint in whichever colourway you chose above.

Set up steps

  1. Install Tampermonkey

    A free browser extension that runs userscripts. Get it from tampermonkey.net and pick your browser. Chrome, Firefox, Edge, Safari and Opera all work.

    Chrome and Edge only: open chrome://extensions (or edge://extensions), click Details on Tampermonkey, and switch on Allow User Scripts, or Tampermonkey will refuse to run anything. On older versions without that switch, turn on Developer mode on the same page instead.
  2. Click the install link

    With Tampermonkey in place, this one link is the whole install:

    Install Twill

    Tampermonkey catches it and shows you the script with an Install button. Press it. Then go to wolvden.com and the Twill mark is in the bottom right corner of every page. Click it, or press Alt+K.

    If the link opens as a wall of text instead, Tampermonkey did not catch it. Select all of it, then open the Tampermonkey dashboard, click the + tab, delete the starter script that appears, paste, and save with Ctrl+S. That is the old way round and it works just as well.

Updating later

Nothing to do. Tampermonkey checks for a new version on its own and updates you. Everything you have written and set stays exactly where it is, every time.

Don't want to wait? Click the Tampermonkey icon in your browser and choose Check for userscript updates, or simply click the install link again. Either way, if Tampermonkey asks before installing the new version, say yes.

Accessibility

Fishing colours are now given an upgrade for those with red-blind or green-blind colour vision, or those who may struggle to see the ripple during fishing. Twill does not point to the fish, but merely acts as a coloured pane put over the browser to add a little more contrast.

Everywhere

Eight themes with a live editor, a corner button that can wear the mark in any of its three colourways or stay a plain labelled button, three of the themes (Tree Bark, Understory and Frosted Cranberries) drawn from Twill's own colours, and every swatch in every one of them is yours to change, a post composer that catches those pesky HTML breaks, and Backup so you can carry everything with you to another computer.

Questions

Is this allowed? Will I get in trouble?

Wolvden's rules forbid scripts that play the game: automation, auto-refreshers, anything that clicks or submits for you. Twill does none of that. It reads a page you opened yourself and changes how it looks, which is the same thing a custom den layout does.

Twill was checked with the Wolvden mod team before it was shared, and changed where they asked. It is still an unofficial user script, not affiliated with Wolvden or Lioden Ltd, and you use it at your own risk. Please bring any Twill trouble to us, never to Wolvden staff.

Does it send my data anywhere?

No. There is no server, no account and no analytics. Your notes, lore and records sit in your own browser's storage and go nowhere, and Twill itself never sends or fetches anything. The script is plain readable text, so you can check that yourself.

One honest footnote: Tampermonkey checks the site it was installed from now and then to see whether a newer version exists. That is the extension doing it, not Twill, and it is what saves you reinstalling by hand. It tells GitHub only what any visit to a web page tells a host. If you would rather it did not, turn updates off for Twill in Tampermonkey's dashboard and nothing else changes.

The file is over half a megabyte. Will it slow the site down?

No. Most of that is the offline reference data: every base, eye colour, marking, mutation, recipe, herb, prey item and battle enemy. It is parsed once when a page loads and then sits in memory. Keeping it in the file is what lets the guides work without ever contacting the wiki.

Do I have to use all of it?

No. Every module has its own switch under Modules in the hub. Turn off what you do not want and it stops building anything at all, rather than merely hiding.

What happens to my notes if I reinstall or update?

Nothing. Everything is stored under keys that have never changed, even though the kit itself has been renamed more than once. Updating keeps everything you have written and set, whether Tampermonkey does it for you or you paste a new version over the old one. If you are moving to another computer, use Backup in the hub, because browser storage does not follow you.

Does it work on a phone?

Yes, wherever userscripts themselves run, which is the real limit rather than Twill. Firefox on Android can run Tampermonkey; Safari on iOS needs a separate app such as Userscripts.

On a narrow screen the hub stops being a floating card and spans the width, the tray runs along the bottom clear of the corner button, and everything you tap is given room for a thumb. Gene cards open on a tap rather than a hover, with a close button. There is no separate mobile version to install: it is the same one file, which simply lays itself out differently below a certain width.

Will it break when Wolvden changes a page?

Possibly, and that is normal for any userscript. It reads the page's structure, so a rebuild of a page can stop a module finding what it needs. Nothing breaks the game itself: the worst case is that a panel stops appearing. Tell us in Discord and it gets fixed.

Can I use it alongside other scripts?

Usually. Twill keeps everything under its own prefix and only adds to a page. If two scripts both decorate the same thing you may get duplicates, so uninstall any older copy of this one before installing this one.

Why does Chrome need an extra switch?

Chrome changed how extensions may run userscripts. Since version 138 each extension has its own Allow User Scripts switch; before that, it took Developer mode. It is Tampermonkey's requirement, not this script's, and every userscript needs it.

Is it free? Can I share it?

Free, and yes. Pass it to anyone. It is made for the Society but nothing in it is guild-locked.

What it will not do

  • It never loads a page for you. No randomly opened tabs.
  • It never clicks, submits or fills a form for you. No auto-explore, bump tools or pre-chosen answers for battles and befriending.
  • It never refreshes anything on a timer. You must manually bump all trade, raffles and chatter posts still.
  • It sends nothing anywhere. No server, no account, no tracking, no analytics.
  • It does not gather up the site. Nothing is kept from Wolvden beyond the wolves you pin to the tray, 8 at most, and they are forgotten when you take them out.
